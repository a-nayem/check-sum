# Alif Nayem Portfolio

A static portfolio for MD Alif Hossain Nayem, built with Three.js and GSAP.

## Preview locally

From this directory, run:

```sh
python3 -m http.server 4173
```

Open `http://localhost:4173`. The interactive 3D scene and GSAP modules load from jsDelivr, so the first preview needs an internet connection. The page keeps its project content and CSS diagrams available if WebGL is unavailable.

The CV download is `assets/Alif-Hossain-Nayem-CV.docx`.
